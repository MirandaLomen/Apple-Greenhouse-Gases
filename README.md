# Apple's Greenhouse Gas Emissions

The goal of this project was to analyze greenhouse gas emissions from the company, Apple, over years 2015-2022. Data analysis includes market capitalization, cause of emissions, emissions per employee, and emissions per product by release year.

Data analysis was performed exclusively by Microsoft Excel via Power Query and Pivot Tables. Visualization also available for viewing via Excel.

Note: Dataset obtained via https://mavenanalytics.io/data-playground.
